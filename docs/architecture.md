# Устройство проекта

- `backend/` — FastAPI, доступ к SQLite, обработка видео, поиск и чат.
- `frontend/src/` — React и стили; `frontend/public/art/` — оптимизированные изображения WebP, шрифт и значок сайта.
- `scripts/serve.py` — запуск API и отдельного обработчика очереди.
- `backend/backup.py` — создание и восстановление переносимой копии.
- `backup/lectory.zip` — начальные пользователи, лекции и связанные файлы.
- `data/` — рабочая база, загруженные файлы и модели. Папка исключена из Git.
- `tests/` — проверки прав, загрузки, очереди, поиска, чата и восстановления данных.

## Обработка

Видео MP4/WebM или ссылка на VK Видео, Rutube, Vimeo → субтитры либо Whisper large-v3 → транскрипт и время слов → E5-эмбеддинги → конспект, оглавление и термины.

Очередь хранится в SQLite. Worker резервирует задачу и продлевает срок её обработки. После аварийной остановки задача снова становится доступна. Сессия распознавания повторно используется внутри worker.

Смысловой поиск сравнивает нормализованные векторы в NumPy. Это подходит для текущего каталога; отдельная векторная база не используется. Поиск и распознавание работают локально, генерация ответов и конспектов — через настроенный сервер ИИ.

## Доступ

Пароли хранятся в виде scrypt-хешей, сеансы — в виде хешей токенов. API проверяет роль и владельца данных; изменяющие запросы проверяют Origin и служебный заголовок. Файлы личных материалов доступны через API после проверки прав.

В резервной копии сохраняются пользователи и хеши паролей, но удаляются активные сеансы и ограничения попыток входа. Рабочая база при этом не меняется. Архив проверяется по SHA-256, целостности SQLite и связям; абсолютные пути заменяются при восстановлении. Существующая база не перезаписывается.

## Ограничения

- Автоматическое распознавание может ошибаться. Субтитры источника также не гарантируют точности.
- Время обработки зависит от длины записи и ресурсов компьютера.
- Начальная копия не синхронизирует независимые установки.
- Доступность внешнего видео и разрешение на встраивание определяет его источник.
- Конфигурация Docker требует отдельной проверки запуска на машине с Docker.
