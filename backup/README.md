# Начальная копия данных

`lectory.zip` содержит пользователей, восемь лекций с транскриптами и материалами, две заявки и связанные локальные файлы.

Копия восстанавливается при первом запуске, если `data/lectory.sqlite3` отсутствует. Существующие данные не заменяются. Данные для входа в три демонстрационных аккаунта приведены в разделе [«Вход» основного README](../README.md#вход). При необходимости создайте своего администратора по той же инструкции.

Модели, сеансы входа, журналы и настройки `.env` в архив не входят. Общий API-ключ находится отдельно в `.env.example`.

Обновление копии:

```sh
python -m backend.cli create-backup --file backup/lectory.zip
```

Создавайте её после завершения фоновой обработки. Это снимок данных, а не синхронизация: новые пользователи и материалы появятся в репозитории только после создания и публикации новой копии.
