# Демонстрация для жюри

Подготовка: выполнить README, загрузить модели заранее и запустить `backend.seed`. Локальные учётные данные находятся в `data/demo-access.txt`. Перед защитой открыть приложение и проверить, что четыре демо-лекции готовы. Подключение API необязательно для поиска, но нужно для генеративных ответов и конспектов.

1. Войти как viewer. Показать каталог и смысловой поиск. Ввести «Как найти длину диагонали комнаты?». Открыть первый результат и показать, что видео и подсветка транскрипта переходят на 0:53.
2. Нажать строку транскрипта или раздел оглавления. Показать переход плеера. Открыть конспект и термины.
3. Спросить: «Как найти диагональ комнаты размером три на четыре метра?». Показать ответ про пять метров и источник на 0:53. Спросить про выпечку хлеба: система должна сообщить об отсутствии данных в лекции.
4. Сохранить закладку и заметку. Открыть «Мою библиотеку», вернуться к видео из сохранённого момента. Подчеркнуть, что заметки личные.
5. Предложить видео по ссылке. Войти как admin, показать очередь, причину отклонения либо одобрение с импортом. Повторное одобрение не создаёт дубликат.
6. Войти как teacher. Загрузить MP4 без SRT, показать очередь и этап распознавания. Для быстрого показа можно загрузить `demo/demo-pythagoras.mp4` вместе с одноимённым SRT. Обработка фоновая, страницу можно закрыть.
7. Для живого импорта использовать публичную лекцию https://www.youtube.com/watch?v=aircAruvnKk. Получение субтитров и воспроизведение зависят от сети источника. Основной показ опирается на локальные видео.
8. Завершить архитектурой, ролями и результатами проверки из презентации. Не обещать независимость внешнего импорта от блокировок источника.
