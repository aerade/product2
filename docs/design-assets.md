# Иллюстрации и визуальный стиль

Шесть отдельных изображений созданы встроенным imagegen. Исходные PNG сохранены в локальной папке сгенерированных изображений, в проект включены оптимизированные WebP. Конвертация формата не меняет содержание. Это 3D-рендеры в растровом формате, отдельные файлы трёхмерных моделей не создавались.

Общая система: светлый фон, тёмно-зелёный цвет, лаймовые акценты, керамика и стекло. Manrope используется с лицензией OFL. Служебные кнопки используют согласованный набор Lucide; сгенерированные иллюстрации сопровождают основные экраны.
