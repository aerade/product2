# Лекторий

Сервис для просмотра видеолекций, смыслового поиска и работы с учебными материалами.
Поддерживает MP4/WebM и ссылки на VK Видео, Rutube и Vimeo.

В репозитории есть начальная копия данных: 4 пользователя, 8 лекций с готовыми материалами и 2 заявки. При первом запуске она восстанавливается в `data/`. Существующая база не заменяется.

## Запуск в Windows

Нужны **Python 3.12**, **Node.js 22+** и Git. Интернет нужен для ИИ, внешних видео и первого скачивания моделей. Для распознавания используется Whisper `large-v3` на CPU: оставьте не менее 8 ГБ свободного диска, а для комфортной обработки рекомендуется 16 ГБ оперативной памяти.

Откройте PowerShell в папке, где хотите сохранить проект:

```powershell
git clone https://github.com/aerade/product2.git
cd product2
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
npm --prefix frontend ci
npm --prefix frontend run build
Copy-Item .env.example .env
.\.venv\Scripts\python.exe scripts/serve.py
```

Откройте **http://localhost:8000**. Сайт и обработчик видео работают, пока запущена последняя команда. Для остановки нажмите **Ctrl+C**.

Для следующего запуска:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
```

## Вход

После восстановления начальной копии доступны три демонстрационных аккаунта:

| Роль | Электронная почта | Пароль |
|---|---|---|
| Зритель | `viewer@demo.local` | `ZO-zpgDoaCYnNFPqVGg` |
| Преподаватель | `teacher@demo.local` | `ZO-zpgDoaCYnNFPqVGg` |
| Администратор | `admin@demo.local` | `ZO-zpgDoaCYnNFPqVGg` |

Данные проверены для копии `backup/lectory.zip`. Если пароль на вашей установке уже изменён, используйте новый пароль.

Чтобы создать собственного администратора с новым адресом, остановите сайт и выполните:

```powershell
.\.venv\Scripts\python.exe -m backend.cli create-admin
.\.venv\Scripts\python.exe scripts/serve.py
```

Команда запросит адрес и пароль. Аккаунты из резервной копии сохранятся.
Обычная регистрация на сайте создаёт зрителя; преподавателей назначает администратор.

## Что доступно на сайте

- Каталог, фильтры и смысловой поиск по всем или выбранным лекциям.
- Плеер, транскрипт, оглавление, конспект и термины с переходами по времени.
- Лектория: чат по материалам сайта, история, изображения и выбор лекции.
- Личные закладки и заметки.
- Предложения видео файлом или ссылкой; просмотр, одобрение, отклонение и удаление заявок.
- Загрузка своих обложек и выбор обложки видео из источника.
- Управление пользователями и лекциями, светлая и тёмная темы.

Зритель смотрит материалы и предлагает видео. Преподаватель также управляет своими лекциями. Администратор управляет всеми лекциями, заявками и ролями. Личные заметки и диалоги доступны только их владельцу.

## Обработка видео и ИИ

По умолчанию используется **Whisper large-v3**, многоязычный вариант, CPU/int8. Если у источника есть субтитры, сайт сначала использует их. Старые транскрипты автоматически не пересоздаются: откройте лекцию и нажмите «Повторить обработку».

Обработка длинного видео может занять много времени. Закрытие страницы её не прерывает. Ошибки распознавания возможны даже у большой модели. У субтитров без времени отдельных слов подсветка приблизительная.

Поиск работает в два этапа: E5 находит до 30 подходящих фрагментов, затем BGE-reranker-v2-m3 повторно оценивает их вместе с вопросом, меняет порядок и отбрасывает слабые совпадения. Это помогает при перефразировании и посторонних запросах. Оценка модели не гарантирует правильность каждого результата.

Модели скачиваются при первом использовании. Дополнительная модель проверки фрагментов занимает около 570 МБ. Первый поиск включает загрузку моделей в память, а повторные одинаковые запросы используют кэш. Чтобы подготовить модели заранее:

```powershell
.\.venv\Scripts\python.exe -m backend.cli download-models
```

В `.env.example` уже настроены сервер ИИ, модель **gpt-6-luna**, средний уровень рассуждения и общий API-ключ. Он доступен каждому, кто получил репозиторий, и использует лимит владельца. Можно заменить `LLM_API_KEY` своим ключом в `.env`. После изменения настроек перезапустите сайт.

Без ключа работают локальный смысловой поиск и распознавание, а вместо генеративных ответов и конспектов используются явно обозначенные выдержки. Доступность внешних видео зависит от источника; если импорт не удался, можно приложить MP4/WebM или SRT/VTT. YouTube не поддерживается.

## Данные и резервная копия

Рабочие пользователи, материалы и загруженные файлы хранятся в **`data/`**. Обновление кода через Git их не удаляет.

Начальная копия находится в **`backup/lectory.zip`**. Она включает базу, локальные видео, субтитры и пользовательские изображения. Модели и активные сеансы входа в неё не входят. Пути к файлам адаптируются к новому компьютеру.

Разные установки получают одинаковое начальное содержимое, но дальнейшие изменения между ними **не синхронизируются**.

Создать свою резервную копию, когда обработка видео завершена:

```powershell
.\.venv\Scripts\python.exe -m backend.cli create-backup --file work/my-backup.zip
```

Скопируйте архив в надёжное место. Для обновления копии в репозитории укажите `--file backup/lectory.zip`, затем сохраните изменение в Git.

На новой установке архив можно восстановить до первого запуска:

```powershell
.\.venv\Scripts\python.exe -m backend.cli restore-backup --file work/my-backup.zip
```

Команда откажется работать, если база уже существует. Если восстанавливаете копию на текущей установке, сначала остановите сайт и переименуйте `data/` в `data-old/` (или другое свободное имя). Затем выполните команду восстановления и запустите сайт. Старую папку сохраните до проверки результата. При своём `DATA_DIR` переименовывайте именно указанную в нём папку.

Для установки с пустой базой задайте `AUTO_RESTORE_BACKUP=false` в `.env` до первого запуска.

## Linux и macOS

Используйте те же шаги, заменив команды Python на `.venv/bin/python`:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
npm --prefix frontend ci
npm --prefix frontend run build
cp .env.example .env
.venv/bin/python scripts/serve.py
```

## Docker

```sh
cp .env.example .env
docker compose up --build -d
```

Сайт доступен на `http://localhost:8000`. При первом запуске копия восстанавливается автоматически; рабочие данные сохраняются в томе Docker.

```sh
docker compose exec lectory python -m backend.cli create-admin
docker compose logs -f
docker compose down
```

Для сохранения данных не удаляйте том. Docker-конфигурация не запускалась в текущей среде: здесь нет Docker daemon.

## Настройки и разработка

Основные настройки `.env`:

| Настройка | Назначение |
|---|---|
| `DATA_DIR` | Папка рабочих данных, по умолчанию `./data` |
| `HOST`, `PORT` | Адрес и порт сайта, `127.0.0.1:8000` |
| `PUBLIC_ORIGIN` | Адрес сайта, по умолчанию `http://localhost:8000` |
| `AUTO_RESTORE_BACKUP` | Восстанавливать начальную копию при отсутствии базы |
| `WHISPER_MODEL` | Модель распознавания, `large-v3` |
| `WHISPER_DEVICE`, `WHISPER_COMPUTE_TYPE` | Устройство и формат вычислений, `cpu` / `int8` |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | Подключение ИИ |
| `LLM_REASONING_EFFORT` | Уровень рассуждения, `medium` |
| `RERANKER_REPO`, `RERANKER_FILE` | Локальная ONNX-модель проверки найденных фрагментов |
| `SEARCH_CANDIDATES` | Сколько фрагментов проверять повторно, по умолчанию 30 |
| `SEARCH_MIN_RELEVANCE` | Минимальная оценка для показа фрагмента, по умолчанию 0.001 |
| `MAX_UPLOAD_MB` | Максимальный размер видео, по умолчанию 500 МБ |

Проверки и сборка:

```sh
python -m pytest -q
npm --prefix frontend run build
```

Для разработки задайте `PUBLIC_ORIGIN=http://localhost:5173` в `.env`. В одном терминале запустите сайт командой `scripts/serve.py` из инструкции выше, в другом — `npm --prefix frontend run dev`. Откройте `http://localhost:5173`: Vite перенаправляет запросы API на порт 8000. API-документация доступна на `http://localhost:8000/docs`.
